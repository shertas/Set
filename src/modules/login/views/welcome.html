Bienvenido al juego online SET

Instrucciones

El objetivo es identificar un SET de 3 cartas de entre las 12 colocadas boca arriba en la mesa. Cada carta tiene cuatro caracterísitcas: número, símbolos, colores y fondo.
Un set es un grupo de tres carta donde cada característica, considerada por separado, es toda igual o toda diferente.

Características de las cartas

  • Número: 1, 2 o 3 figuras
  • Símbolo: óvalo, rombo o curva
  • Color: rojo, verde o morado
  • Fondo: vacío, rayado o sólido

Regla principal

Para formar un set cada característica tiene dos opciones:


  • Todas iguales entre las tres cartas.
  • Todas diferentes entre las tres cartas.

Si una característica coincide solo en dos cartas, no es un set.

Fin del juego

El juego termina cuando se acaba el mazo y ya no queda ningún set. Gana quien tenga más sets reunidos.
